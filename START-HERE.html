Get playing

Choose your starting point.

  1. Install Prism Launcher for Windows. Sign in with your Minecraft Java account.
  2. Download the modpack

    In Prism, choose Add Instance → Import and select the downloaded .mrpack. If using the Windows ZIP, extract it first.

  3. Select 64-bit Java 17. Start with 6 GB allocated on a 16 GB PC; hosting may need 8 GB.
  4. Create a Survival world with World Type: One Mine Piece. Press J, choose Race, Faction and Fighting Style, then click Finish.

The launcher downloads about 521 MiB of mods and shaders, plus Minecraft and Forge. Windows gameplay still needs testing on your PC.

Same world. Different houses.

Host on your gaming PC

  1. Open your world.
  2. Choose Esc → Open to LAN → Start LAN World.
  3. Copy e4mc’s public address from chat and send it to friends.
  4. Keep the world open and your PC awake.

Friends join from anywhere

  1. Install the same pack and addon version.
  2. Open Multiplayer → Direct Connection.
  3. Paste the host’s current public address.

A home IP or local LAN port will not work across the internet. The session ends when the host closes the world.
