New game

Download importable modpack

Import Grand-Line-Odyssey-0.3.0.mrpack using Prism Launcher → Add Instance → Import. The Windows ZIP contains this file plus the guides and update JAR.

Update an existing game

Download update JAR

Close Minecraft and back up your world. Replace the old Odyssey JAR in your instance’s mods folder with grandline-odyssey-0.3.0.jar. A JAR is a mod file; do not double-click it to launch the game.

Open the guide without a server.

Extract the whole Windows ZIP, then open START-HERE.html in Safari, Chrome, Edge or Firefox. Keep all the extracted folders together. On Windows, OPEN-GUIDE.cmd also opens the guide. Navigation, search and instructions work offline.
