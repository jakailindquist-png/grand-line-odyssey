# Grand Line Odyssey

One Piece Minecraft Java modpack website.

- Website: https://jakailindquist-png.github.io/grand-line-odyssey/
- Downloads: https://github.com/jakailindquist-png/grand-line-odyssey/releases/tag/v0.5.0

Release 0.5.0: Minecraft 1.20.1, Forge 47.4.0, 37 pinned third-party downloads and the original Odyssey addon.
Third-party mods download from their authors through the pack manifest; their JARs are not redistributed in this repository.

## Hosting

GitHub Pages publishes the main branch root. All navigation and assets use relative paths; pack downloads use GitHub Releases. No local server is required.

## Validation

See the current full-pack test record in VALIDATION.html. Windows gameplay and internet co-op still require acceptance testing. See VALIDATION.html for the scope and limitations.
